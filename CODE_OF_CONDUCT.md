# Code of Conduct

This project is committed to providing a friendly, safe, and welcoming environment for everyone.

## Our Standards

Examples of positive behavior include:

- Being respectful and inclusive in language and actions
- Assuming positive intent and giving constructive feedback
- Focusing on what is best for the community and users

Examples of unacceptable behavior include:

- Harassment, discrimination, intimidation, or personal attacks
- Trolling, insulting comments, and deliberate disruption
- Publishing private information without explicit permission

## Scope

This Code of Conduct applies in project spaces, including issues, pull requests, discussions, and other community channels.

## Reporting

If you experience or witness unacceptable behavior, report it through GitHub private maintainer contact channels where available.
For urgent moderation issues in repository interactions, open an issue titled "Code of Conduct concern" with only high-level context; maintainers will follow up privately.

## Enforcement

Maintainers are responsible for clarifying and enforcing community standards and may remove or edit comments, commits, code, and other contributions that violate this policy.
