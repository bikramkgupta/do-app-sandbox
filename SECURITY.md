# Security Policy

## Supported versions

Security fixes are applied to the latest release on `main`.

## Reporting a vulnerability

Please use GitHub Security Advisories ("Report a vulnerability") for private disclosure.

If that path is unavailable, open an issue with minimal detail and request a private follow-up from maintainers. Do not publish exploit details publicly before a fix is available.

## Response goals

- Initial triage acknowledgment: within 3 business days
- Severity assessment and plan: within 7 business days
- Public disclosure after fix is available and users have guidance

## Coordinated disclosure

We request coordinated disclosure and will credit reporters unless anonymity is requested.
